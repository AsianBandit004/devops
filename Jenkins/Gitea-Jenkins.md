# Gitea-Jenkins
This was a project I worked on to host Jenkins and Gitea locally on my Proxmox server.
This allowed me to integrate both of the services running and enabled me to use local git commands 
through my MAC to automate building and testing my code.

For the test process, I used a basic Jenkins file and echoed a few statements.
