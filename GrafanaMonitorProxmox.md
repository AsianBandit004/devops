# Granfa Monitoring Service For Proxmox
Wanting to be able to monitor all aspects of my on-prem server (clustered NUCs w/ R730), I ingest logs from Proxmox and use influxDB to create beautiful graphs with Grafana 
This not only enables me to closely keep an eye on server performance but also the VMs and LXC containers hosted and created on the cluster itself.
